# ======================================================================
# FLAME Detection Rule: Combo List Iteration Pattern
# ======================================================================
#
# This rule uses aggregation/correlation logic that requires
# SIEM-native implementation. It cannot be auto-converted to
# SPL/Lucene/KQL by pySigma backends.
#
# Level: high
# CFPF Phase: P2
# Threat Paths: TP-0013, TP-0001
#
# Description:
#   Detects sequential username patterns typical of combo list iteration
#   during credential stuffing attacks. Attackers feed sorted credential
#   lists into stuffing tools, producing login attempts where usernames
#   appear in alphabetical or near-alphabetical order with minimal timing
#   variation between attempts, a pattern never seen in organic user
#   behavior.
#
# ----------------------------------------------------------------------
# Log Source
# ----------------------------------------------------------------------
#   product: banking
#   service: auth_logs
#
# ----------------------------------------------------------------------
# Detection Logic (Sigma YAML)
# ----------------------------------------------------------------------
#   selection:
#     event_type: login_attempt
#     auth_result: failure
#   timeframe: 10m
#   condition: 'selection | count(distinct username) by source_ip > 15 and stddev(inter_event_time)
#     by source_ip < 500ms
#   
#     '
#
# ----------------------------------------------------------------------
# Known False Positives
# ----------------------------------------------------------------------
#   - Automated batch user provisioning systems that test accounts sequentially
#   - QA test suites running ordered account validation during deployments
#
# ======================================================================
# Implementation Notes:
#   - Review the condition syntax and implement using your SIEM's
#     native aggregation/correlation capabilities
#   - Splunk: Use 'stats' or 'transaction' commands
#   - Elastic: Use EQL sequences or aggregation queries
#   - Sentinel: Use KQL summarize/make-series operators
# ======================================================================

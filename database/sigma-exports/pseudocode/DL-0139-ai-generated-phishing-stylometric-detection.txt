# Description:
#   Detects AI-generated phishing content using stylometric features.
#   Research shows XGBoost with 60 stylometric features detects
#   GPT-4o-generated phishing with 96% accuracy and 99% AUC. Key features:
#   imperative verb count, clause density, first-person pronoun usage,
#   urgency markers, authority indicators, sentiment manipulation,
#   financial trigger words, and semantic inconsistency. DetectGPT achieves
#   ~0.95 AUROC via zero-shot statistical signatures. This rule defines the
#   feature extraction pipeline and scoring thresholds for deployment in
#   email security and fraud communication analysis systems.
#
# ----------------------------------------------------------------------
# Log Source
# ----------------------------------------------------------------------
#   product: email_security
#   service: content_analysis
#
# ----------------------------------------------------------------------
# Detection Logic (Sigma YAML)
# ----------------------------------------------------------------------
#   selection:
#     content_type: email
#   condition: 'stylometric_score > 0.75 (composite of 60 features) AND (urgency_marker_count
#     > 3 OR authority_indicator_count > 2) AND imperative_verb_ratio > 0.15
#   
#     '
#
# ----------------------------------------------------------------------
# Known False Positives
# ----------------------------------------------------------------------
#   - Legitimate marketing emails with urgency language
#   - Automated compliance notifications with authority language
#   - Translated emails with unusual stylometric patterns
